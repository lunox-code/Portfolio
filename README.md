# Lunox Code — Portfolio

A small personal portfolio built with plain HTML, CSS, and JavaScript. There are no packages to install.

## Open and preview

Open `index.html` in a browser to see the page. In VS Code, edit a file, save it, and refresh the browser.

## Make it yours

- In `index.html`, replace the sample project descriptions with projects you build. Your name and contact link are already filled in.
- In `style.css`, change the colors near the top in the `:root` block. Those variables control the shared colors and fonts.
- In `script.js`, the small-screen menu opens and closes, and the copyright year updates automatically.

## The three web files

- `index.html` describes the page content and its sections.
- `style.css` controls colors, spacing, typography, and the mobile layout.
- `script.js` adds the menu interaction and current year.
